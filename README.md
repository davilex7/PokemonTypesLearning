## 📖 Descripción

**Pokémon Types Learning** es una aplicación web interactiva diseñada para ayudarte a memorizar y dominar la tabla de tipos Pokémon. Perfecta tanto para jugadores casuales que quieren mejorar su conocimiento como para entrenadores competitivos que necesitan tomar decisiones rápidas en combate.

El juego presenta preguntas aleatorias sobre efectividades de tipo, poniendo a prueba tu conocimiento de:
- ⚔️ **Ataques super efectivos** (x2)
- 🛡️ **Resistencias** (x½)
- 🚫 **Inmunidades** (x0)
- ⚖️ **Daño neutral** (x1)

## ✨ Características

<table>
<tr>
<td width="50%">

### 🎯 Modo Identificar
- Identifica qué tipos son **fuertes** o **débiles** contra un tipo dado
- Preguntas del estilo: *"Fuego → Fuerte contra..."*
- Cuadrícula 2x2 con opciones de respuesta
- Indicadores visuales de color por tipo

</td>
<td width="50%">

### 🧮 Modo Calculadora
- Determina el multiplicador de daño entre dos tipos
- Visualiza: *Tipo Atacante → Tipo Defensor*
- Opciones: x0, x½, x1, x2
- Animación de flecha pulsante

</td>
</tr>
</table>

### 🏆 Sistema de Puntuación
| Métrica | Descripción |
|---------|-------------|
| **Racha** | Respuestas correctas consecutivas actuales |
| **Récord** | Tu mejor racha histórica de la sesión |

### 🎨 Experiencia Visual
- 🌙 **Tema oscuro** elegante y cómodo para la vista
- 🎨 **Colores oficiales** de cada tipo Pokémon
- ✨ **Animaciones suaves** de fade-in y feedback
- 📱 **100% Responsive** - funciona en móvil, tablet y desktop
- 👆 **Optimizado para touch** - experiencia fluida en dispositivos táctiles

## 🕹️ Cómo Jugar

```
1. 🚀 Abre Poke-Quiz.html en tu navegador
2. 👀 Lee la pregunta que aparece en pantalla
3. 🤔 Analiza las 4 opciones disponibles
4. 👆 Selecciona tu respuesta
5. ✅ Verde = ¡Correcto! | ❌ Rojo = Incorrecto (se muestra la respuesta correcta)
6. 🔄 La siguiente pregunta aparece automáticamente
7. 📈 ¡Intenta superar tu récord!
```

## 🚀 Instalación

¡No necesitas instalar nada! Es una aplicación 100% client-side.

### Opción 1: Clonar repositorio
```bash
git clone https://github.com/tu-usuario/PokemonTypesLearning.git
cd PokemonTypesLearning
```

### Opción 2: Descarga directa
Simplemente descarga el archivo `Poke-Quiz.html`

### Ejecutar
```bash
# Abre directamente en el navegador
open Poke-Quiz.html          # macOS
xdg-open Poke-Quiz.html      # Linux
start Poke-Quiz.html         # Windows

# O usa un servidor local (opcional)
python -m http.server 8000
# Navega a http://localhost:8000/Poke-Quiz.html
```
